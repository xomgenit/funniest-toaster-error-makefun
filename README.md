Entry for the [make.fun bounty "The Funniest Toaster Error Message"](https://make.fun/c/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd): one line, at most 120 characters — the error message a kitchen toaster shows its owner.

The program writes the entry to `/output/entry.txt` (via `MAKEFUN_OUTPUT_DIR` or `out`).

## Entry

> Toast ejected. It has chosen a new life on the floor. I will not be retrieving it.

## Run

```sh
node main.ts
```
